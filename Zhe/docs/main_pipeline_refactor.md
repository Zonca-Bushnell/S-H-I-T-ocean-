# Eddy Pipeline Refactor

This document records the first production refactor of the Verify / S-H-I-T-ocean codebase.

## Production Interface

The production entrypoint is now:

```bash
python -m src.eddy_pipeline.cli run-detection-to-shape ...
python -m src.eddy_pipeline.cli build-representative --orientation turned|unturned|both ...
python -m src.eddy_pipeline.cli run-all ...
```

The default scientific contract is:

```text
hua_b3_start2 + 30-180d bandpass + boundary_monotonic + strict_contiguous
+ life30 + coherent_only + ME_LIUTEX azimuth_preserved + global_ls_alpha
```

`src.data_downloading` is intentionally outside this refactor.

## Production Package

`src.eddy_pipeline` is the source of truth for the identification-to-composite chain:

- `contracts.py`: default parameters, method names, and strict-contiguous depth policy.
- `detection_hybrid.py`: Hua/Nencioli SSH + velocity hybrid per-layer detection.
- `tracking.py`: object-voxel feature/group tracking.
- `catalog.py`: strict-contiguous catalog adapter and life30 shape adapter.
- `shape.py`: 3D shape classification implementation.
- `radial_representative.py`: coherent-only radial seed representative vortex.
- `representative.py`: ME_LIUTEX azimuth-preserved TURN/UNTURN structure composite.
- `cli.py`: production command-line interface.
- `utils/`: shared config, table IO, CMEMS time-series reading, and velocity-grid helpers.

## Compatibility Wrappers

The old production paths under `src.Legacy.Location` remain as thin wrappers so old commands fail less abruptly. New code should not import production logic from `src.Legacy.Location`; it should use `src.eddy_pipeline`.

Promoted wrappers include:

- `src.Legacy.Location.run_acc_hua_b3_pipeline -> src.eddy_pipeline.cli`
- `src.Legacy.Location.run_hua_hybrid_detection_acc -> src.eddy_pipeline.detection_hybrid`
- `src.Legacy.Location.run_hua_feature_group_tracking_acc -> src.eddy_pipeline.tracking`
- `src.Legacy.Location.hua_b3_catalog_adapter -> src.eddy_pipeline.catalog`
- `src.Legacy.Location.classify_3d_eddy_shape -> src.eddy_pipeline.shape`
- `src.Legacy.Location.run_representative_vortex -> src.eddy_pipeline.radial_representative`

## Legacy Areas

Non-production diagnostics and paper replication scripts were moved under `legacy/`:

- `legacy/diagnostics/`: one-off plotting and object diagnostics.
- `legacy/method_comparison/`: Nencioli/Hua comparisons and boundary-monotonic experiments.
- `legacy/paper_replication/`: Li/Yang/Xu, MITgcm, and mode-tilt experiments.

These scripts are useful research history, but they are not production entrypoints.

## Representative Vortex Policy

Only this structural representative vortex is production:

```text
boundary-monotonic + strict-contiguous + life30 + coherent-only
+ ME_LIUTEX azimuth-preserved + global_ls_alpha
```

TURN and UNTURN are both generated by `src.eddy_pipeline.representative`:

- `--orientation turned`: global-alpha turned composite.
- `--orientation unturned`: east/north structural control.
- `--orientation both`: produce both directories.

Older radial-only, all-shape, non-boundary-monotonic, and non-strict-contiguous composites are legacy comparison products.
