\begin{abstract}
本文把当前 core-shell 经验分区升级为 V2 判据：不再要求一个低泄漏材料边界同时圈住 Hua/LAVD 旋转核与 PV anomaly 动力核，而是把涡旋拆成
\[
\mathcal{T}_{total}
=
\mathcal{T}_{core}^{trap}
+
\mathcal{T}_{shell}^{stir}
+
\mathcal{T}_{exchange}.
\]
其中 inner material core 用于 trapping/material coherence，PV-active shell 用于 heat/PV stirring 与 EP 倾斜修正，exchange layer 用于解释边界热、PV 与动量交换。这个划分并不是为了逃避闭合，而是为了避免把物理角色不同的区域强行塞进同一个材料体。
\end{abstract}

\section{为什么需要 V2 分区}

单一材料涡体积假设要求同一个边界同时满足三件事：低泄漏、包住速度/旋转相干核、包住主要 PV anomaly。我们的现有验证显示，这个要求过强。

第一，Hua 弱速中心与 LAVD 旋转相干中心通常较接近，说明运动学旋转核可以作为材料 trapping core 的候选。第二，PV anomaly core 与 Hua/LAVD core 存在系统性分离，PV 高值区更容易出现在外壳、强剪切带或月牙强速带附近。第三，EP 倾斜修正不是小量，且其绝对贡献更偏向 shell。若继续强迫
\[
PV\ core \subset M_{LAVD},
\]
就会把低泄漏的材料相干问题和 PV/热输送问题混成一个过约束问题。

\section{文献约束}

Haller 与 Beron-Vera 的 geodesic eddy 理论强调有限时间内低拉伸、低泄漏的闭合材料曲线 \cite{HallerBeronVera2013}。Haller 等人的 LAVD 方法强调由轨迹涡度偏差积分定义客观旋转相干核 \cite{HallerEtAl2016}。这两类理论适合定义 inner material core，但它们并不要求 PV anomaly 最大区必须在同一边界内。

Abernathey 与 Haller 对 eastern Pacific 的研究指出，Eulerian 涡旋与 Lagrangian coherent vortex 并不等价，表观涡输送会受到 filamentation 和 leakage 影响 \cite{AbernatheyHaller2018}。Zhang、Wolfe 与 Abernathey 的 PV 输送研究进一步支持 coherent core 与 periphery/shell 的分账：PV transport 不应只归因于低泄漏 core \cite{ZhangWolfeAbernathey2020}。

热输送方面，Hausmann 与 Czaja、Dong 等工作都说明 mesoscale eddy heat transport 需要使用协方差或乘积后平均，而不能用平均结构相乘代替 \cite{HausmannCzaja2012,DongEtAl2014}。因此 V2 分区必须保存
\[
\langle v'X'\rangle_M,\quad
\langle v'\rangle_M\langle X'\rangle_M,\quad
\langle v'X'\rangle_M-\langle v'\rangle_M\langle X'\rangle_M,
\]
其中 \(X=\theta\) 或 \(q\)，\(M\) 可以是 inner core、PV-active shell 或 combined volume。

\section{V2 分区判据}

\subsection{Inner material core}

Inner material core 的物理角色是 trapping/material coherence。它不是全部输送的代表区，而是低泄漏、旋转相干、弱速核心连通的材料核。

\begin{itemize}
  \item 默认范围：\(r/R \le 1.2\)。
  \item 中心约束：Hua 弱速中心与 LAVD 旋转中心近同位；若使用代表涡，则默认 axis source 为 radial seed，可显式改为 composite-Hua refined axis。
  \item 核心约束：低 \(|\bm{u}'|\) 区域连通，weak-core retention 不低于 0.75。
  \item 边界约束：优先使用 levelset/geodesic/LAVD 类低 leakage 边界；boundary leakage 与 particle retention 必须单独记录。
\end{itemize}

\subsection{PV-active shell}

PV-active shell 的物理角色是 stirring。它可以不是严格材料边界，因为它承担的是 PV anomaly、热异常和动量异常的交换与协方差输送。

\begin{itemize}
  \item 默认范围：inner core 外侧到 \(r/R \le 2.5\)。
  \item PV 判据：取 shell domain 内 \(|q'|\) 前 20\%，即默认 \(Q_{0.80}(|q'|)\) 以上。
  \item 剪切判据：优先保留高 \(|\nabla q'|\)、强速度剪切或月牙强速带区域。
  \item 连通判据：保留围绕 inner core 或 PV centroid 的主连通区，但不要求完全低 leakage。
\end{itemize}

\subsection{Exchange layer}

Exchange layer 是 inner core 和 PV-active shell 的界面，不应被解释为 trapping core，也不应被并入内部 EP forcing。

\begin{itemize}
  \item 默认范围：inner core 边界外侧 1--2 个网格，或 inner core 与 PV shell 的接触带。
  \item 预算项：
  \[
  \oint_{\partial M}\rho_0 C_p\theta' u_n\,dS,\quad
  \oint_{\partial M}q'u_n\,dS,\quad
  \oint_{\partial M}b'u_n\,dS,\quad
  \oint_{\partial M}u_i'u_n\,dS.
  \]
  \item 判读：若 exchange 不小，说明闭合残差可能来自 core-shell 交换，而不是 EP 公式本身错误。
\end{itemize}

\section{判读规则}

若 inner material core 低 leakage、高 retention，但 heat/PV covariance 弱，则它应被解释为 trapping/material core。若 PV-active shell 的 \(v'\theta'\)、\(v'q'\) 与 \(F_z^{tilt\ correction}\) 更强，则输送主结论应写在 shell 上。若 exchange layer 的 heat/PV/momentum 通量不小，则 single material volume 闭合不成立，但 core-shell-exchange 分账仍然成立。

因此 V2 的核心判定不是 ``是否找到一个完美材料涡''，而是：
\[
\text{material core 是否稳定},\quad
\text{PV shell 是否承载 stirring},\quad
\text{exchange 是否解释闭合残差}.
\]
